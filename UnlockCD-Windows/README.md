# UnlockCD-Windows (lab kit)

**English** · [Español](#español)

## English

This folder is **not** a complete, tested pipeline to boot an iOS ramdisk on Windows.

What you see here are **lab experiments**, partial automation, and **failed or unfinished attempts** we kept while reverse‑engineering UnlockCD. Scripts may be wrong, outdated, or missing steps that the macOS app performs inside encrypted `start.sh` / `mnt2.macho`.

We publish it anyway so others can **inspect, diff, and improve** — not so you can treat it as a product.

If you get a working boot + SSH + `/mnt2` flow on Windows, please open an issue on the main repo and describe what changed.

---

## Español

Esta carpeta **no** es un flujo completo ni probado para arrancar un ramdisk iOS en Windows.

Lo que hay son **experimentos de laboratorio**, automatización a medias e **intentos fallidos o incompletos** que fuimos guardando al estudiar UnlockCD. Los `.bat` pueden estar mal, desactualizados o faltar pasos que la app Mac hace en `start.sh` / `mnt2.macho` cifrados.

Lo subimos igual para que podáis **investigar, comparar y mejorar** — no usarlo como herramienta terminada.

Si lográis boot + SSH + `/mnt2` estable en Windows, abrid un issue en el repo principal contando qué corregisteis.
